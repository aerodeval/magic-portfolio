## Overview

I made this project when i had just started listening to Tame Impala, as his songs grew onto me they also did inspire me to build something creative and artistic
## Key Features

- **Acertinity UI**: Implemented components using Acertinity UI which enhanced the UI of the webpage and gave it a clean aesthetic. Manu Paji's team has done a great job with the library!
- **NextJS Framework**: Built on NextJS Page routing for faster page loads.

## Technologies Used

- **React and Next.js**: For building the front-end codebase with clean, reusable components.


## Challenges and Learnings

One of the Learnings from this project was to learn how to work with cross platform and browser compatibility with plug and play components. It was an hassle to optimize these components and make them responsive according to the devices.
## Outcome

Building this website in **Next.js** helped me explore new Technologies and also portray my creative skills.  
- I implemented **internal page routing**, so each game has its own dedicated page where I could dive deep into the experiences, stories, and lessons I took away.  
- The project taught me how to connect a modern React framework with a cloud backend, while still keeping performance smooth and navigation intuitive.  

This project not only serves as a personal as a demonstration of my creative skills but also my love for the artist.
