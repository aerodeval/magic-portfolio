## Overview

Development of an interactive and scalable seat selection and booking platform, enabling real-time seat visualization, selection, and confirmation using Next.js for front-end and Figma for design collaboration.

## Key Features

- **Dynamic Seat Maps**: Implemented responsive, grid-based seat layouts that adapt to different venues and seating arrangements.  
- **Interactive Selection**: Built intuitive seat selection with hover states, availability indicators, and live price updates for a seamless user experience.  
- **Booking Flow**: Designed and developed a streamlined booking process with seat confirmation, payment integration, and booking summary views.  
- **Design Collaboration**: Partnered with designers via a shared Figma workspace to create consistent UI patterns and iterate quickly on seat map visualizations.  
- **Reusable Components**: Developed modular UI components (seat cards, legends, filters, modals) to ensure scalability across events and venues.  

## Technologies Used

- **Next.js**: For server-side rendering and efficient front-end performance.  
- **Figma**: For designing seat maps, user flows, and ensuring consistent design handoffs.  
- **TailwindCSS**: For rapid, responsive UI development with utility-first styling.  
- **React Context/Redux**: For managing seat selection state and booking logic.  

## Challenges and Learnings

A key challenge was handling **real-time seat availability** in high-traffic scenarios while maintaining smooth UI interactions. This was solved through efficient state management and conditional rendering strategies. Another challenge was designing **scalable seat maps** that could adapt to small theaters as well as large stadiums, which required modular layout logic and reusable seat components.  

## Outcome

FinalSeat now delivers a **fast, user-friendly seat booking experience** across multiple event types. The platform reduces booking friction, improves venue seat visualization, and increases user satisfaction. It has provided a **scalable foundation** for expanding into different event categories while maintaining consistency in design and performance.
