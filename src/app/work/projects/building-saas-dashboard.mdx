## Overview

Developed this dashboard in two days for a product where the design was inspired from a wow UI design. It has functionalities such as theme switching, order searching and order filtering based on order status.
## Key Features

- **Reusable Components**: Developed components to be reusable used MUI components such as card, table, menu, etc.  
- **Theme Switching**: Developed theme switching using MUI themes and design variables exported from design.
- **Simulated API data**: Simulated data in content.js from api calls so changing component data is easier and less code clutter.  

## Technologies Used

- **ReactJs**: For server-side rendering and efficient front-end performance.
- **Recharts**: Used Recharts to display dynamic data for dashboard.   
- **Figma**: For designing seat maps, user flows, and ensuring consistent design handoffs.  
- **Material UI**: For rapid, responsive UI development with utility-first styling.  
- **React Context/Redux**: For managing theme switching state and logic.  

## Challenges and Learnings

A key challenge was handling **theme switching** since mui was not compatible with using root variables. Other thant that also making recharts responsive in dashboard was diffcult in such a short timeframe but ended up making the product responsive and clean.  

## Outcome

Dashboard smoothly delivered.
