## Overview

In this project, I focused on making an application to log all my gaming experiences at one place and to look back on the memories made.

## Key Features

- **Firebase Auth & Database Integration**: Implemented Firebase for user authentication and for storage of data regarding the game and also the photos.
- **NextJS Framework**: Built on NextJS Page routing for faster page loads.
- **Continuous Sync**: Established a CI/CD pipeline that continuously synchronizes design changes from GitHub to the webpage, ensuring design updates are reflected instantly.

## Technologies Used

- **React and Next.js**: For building the front-end codebase with clean, reusable components.
- **Firebase**: For Storage and authentication to webpage.
- **Firebase**: For Storage and authentication to webpage.

## Challenges and Learnings

One of the Learnings from this project was the need for a cdn network to host images as my spark plan in firebase expired in instant as all images were getting hosted and utilising the free tier usage costs.
## Outcome

Building my **Games Memoir** website in **Next.js** with **Firebase** gave me a space to document and reflect on my gaming journey.  
- I implemented **internal page routing**, so each game has its own dedicated page where I could dive deep into the experiences, stories, and lessons I took away.  
- Using **Firebase**, I was able to store and fetch my memoir entries seamlessly, making the site dynamic and scalable.  
- The project taught me how to connect a modern React framework with a cloud backend, while still keeping performance smooth and navigation intuitive.  

This project not only serves as a personal archive of my gaming experiences, but also as a demonstration of how I can combine **frontend frameworks** and **cloud services** to create meaningful, interactive web applications.
